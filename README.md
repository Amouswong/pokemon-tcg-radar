# 🎴 寶可夢卡牌搜尋雷達

一個幫助你在日本尋找販售寶可夢卡牌的便利店和專門店的互動地圖工具。

## 功能特點

- 📍 顯示日本各地的便利店（7-Eleven、Lawson、FamilyMart）
- ⭐ 標記寶可夢中心和卡牌專門店
- 🎯 搜尋範圍功能：設定半徑查找附近店舖
- 🗺️ 路線規劃：計劃最佳訪問路線
- ✅ 標記已到訪的店舖
- 🔍 多層級地圖顯示：縣級、市級、店舖級

## 使用方法

1. 打開網站
2. 使用定位按鈕找到你的位置（需要在日本）
3. 使用篩選功能選擇要顯示的店舖類型
4. 點擊店舖標記查看詳情和導航
5. 使用搜尋範圍功能找出特定半徑內的所有店舖

## 技術架構

- 純前端 HTML/CSS/JavaScript
- Leaflet.js 地圖庫
- OpenStreetMap 地圖數據
- 本地存儲記錄已到訪店舖

## 數據來源

- 便利店數據：5,791+ 個位置
- 寶可夢店舖：精選的寶可夢中心和卡牌店
- 城市中心數據：日本主要縣市
